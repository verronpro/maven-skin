= Maven Skin
Joseph Verron
:toc:
:toclevels: 3

A modern, tech-blog styled Maven site skin designed for open-source developers.
Maven Skin brings a contemporary look to your Maven documentation with dark/light mode support,
fully responsive design, and automated table of contents generation.

== Features

=== Modern Design
- **Tech-Blog Style**: Clean, minimalist design inspired by modern tech blogs
- **Dark/Light Mode**: Automatic theme switching to match system preferences or user selection
- **Responsive Layout**: Beautiful on mobile phones, tablets, and desktop screens
- **Report Tables**: Properly formatted responsive tables for Maven reports (test reports, coverage, etc.)

=== Developer-Friendly
- **Automatic Table of Contents**: Generate a dynamic TOC for any page automatically
- **AsciiDoc First**: Built with AsciiDoc users in mind
- **Configurable Colors**: Theme colors can be customized to match your project's branding
- **Pluggable Elements**: Enable or disable UI elements easily

=== Performance & Accessibility
- **Lightweight**: Minimal dependencies and fast loading
- **Semantic HTML**: Proper semantic markup for accessibility
- **SEO Ready**: Sitemap generation and proper metadata support

== Quick Start

=== Prerequisites
- Maven 3.9+ (latest version recommended)
- Java 21+

=== Installation

Add the Maven Skin dependency to your project's `pom.xml`:

[source,xml]
----
<project>
  <skin>
    <groupId>pro.verron</groupId>
    <artifactId>maven-skin</artifactId>
    <version>1.0</version>
  </skin>
</project>
----

That's it! Your Maven site will now use the modern Maven Skin theme.

=== Configuration

Basic Maven site configuration in your `pom.xml`:

[source,xml]
----
<project>
  <build>
    <plugins>
      <plugin>
        <groupId>org.apache.maven.plugins</groupId>
        <artifactId>maven-site-plugin</artifactId>
        <version>3.21.0</version>
        <configuration>
          <generateSitemap>true</generateSitemap>
          <asciidoc>
            <attributes>
              <source-highlighter>coderay</source-highlighter>
            </attributes>
          </asciidoc>
        </configuration>
      </plugin>
    </plugins>
  </build>

  <skin>
    <groupId>pro.verron</groupId>
    <artifactId>maven-skin</artifactId>
    <version>1.0</version>
  </skin>
</project>
----

----

Run: `mvn site`

=== With Dark/Light Mode

The skin automatically includes dark/light mode toggle. Users can:

- Click the theme toggle button to switch themes
- The preference is saved in their browser
- System preference is used by default

=== Using the Automated Table of Contents

Simply add the `:toc:` attribute to your AsciiDoc files:

[source,asciidoc]
----
= Document Title
:toc:
:toclevels: 3

Your content here...
----

The skin will automatically generate and display a navigable table of contents.

=== Responsive Tables for Reports

Maven Skin automatically handles report tables responsively:

- Test reports display correctly on mobile with horizontal scrolling
- Code coverage tables adapt to screen size
- Project info is properly formatted on all devices

== Customization

=== Theme Colors

*(Coming in future releases)* You'll be able to customize theme colors by:

[source,xml]
----
<plugin>
  <groupId>org.apache.maven.plugins</groupId>
  <artifactId>maven-site-plugin</artifactId>
  <configuration>
    <skin>
      <colors>
        <primary>#007bff</primary>
        <secondary>#6c757d</secondary>
        <accent>#28a745</accent>
      </colors>
    </skin>
  </configuration>
</plugin>
----

=== Enabling/Disabling Features

*(Coming in future releases)* Control which UI elements appear:

[source,xml]
----
<configuration>
  <skin>
    <features>
      <tableOfContents>true</tableOfContents>
      <darkModeToggle>true</darkModeToggle>
      <searchBox>true</searchBox>
      <breadcrumb>true</breadcrumb>
    </features>
  </skin>
</configuration>
----

== Supported Maven Versions

Maven Skin supports **the latest version of Maven only** (currently 3.9+).

If you're using an older Maven version, you can:

- Upgrade to the latest Maven version
- Use a previous version of Maven Skin that supports your Maven version
  (older skin versions will be maintained for historical support)

We recommend upgrading to the latest Maven version for better performance, security, and features.
