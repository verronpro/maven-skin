= Maven Skin
:toc:

A modern, tech-blog styled Maven site skin for open-source projects.

== Features

🎨 **Modern Design** - Clean, tech-blog aesthetic
🌓 **Dark/Light Mode** - Automatic theme switching
📱 **Fully Responsive** - Beautiful on all devices
📄 **AsciiDoc First** - Perfect for technical documentation
🎯 **Automated TOC** - Table of contents generation
⚡ **Fast & Lightweight** - Minimal dependencies
🔧 **Configurable** - Customize colors and elements
🌐 **SEO Ready** - Automatic sitemap generation

== Quick Start

Install Maven Skin in your `pom.xml`:

[source,xml]
----
<skin>
  <groupId>pro.verron</groupId>
  <artifactId>maven-skin</artifactId>
  <version>1.0</version>
</skin>
----

Generate your site:

[source,bash]
----
mvn site
----

Open `target/site/index.html` in your browser.

For detailed instructions, see the link:getting-started.html[Getting Started] guide.
